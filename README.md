# IPTV Player (Android Phone + Android TV)

مشغل IPTV لهاتف أندرويد وأجهزة التلفاز (Android TV)، بواجهة عربية RTL بتخطيط سطح المكتب:
شريط جانبي، صفوف أفقية، وأعمدة (تصنيفات / قنوات / معاينة).

## الحالة: المرحلة 2.6
- الرئيسية بأشرطة: أهم المباريات (من دليل برامج قنوات beIN عبر Xtream)، المفضلة، مسلسلات أتابعها، أهم المسلسلات المضافة مؤخراً.
- البث المباشر والأفلام والمسلسلات مع معاينة ومشغل Media3 بملء الشاشة.
- نجمة ☆ للمفضلة، والضغط المطوّل على أي باقة أو عنصر لسحبه وتغيير ترتيبه (زر "الترتيب الأصلي" للتراجع).
- يتذكر آخر حلقة وموضع المشاهدة لكل مسلسل.
- التطبيق يعمل بوضع أفقي تلقائياً.
- الرئيسية: «مباريات اليوم» ببطاقات بشعارات الفرق والنتيجة والدقيقة (مصدرها ESPN)، ثم مسلسلات أتابعها، المفضلة، المسلسلات المضافة حديثاً بنفس تنسيق الأغلفة.
- الأفلام والمسلسلات: قائمة التصنيفات على جانب وشبكة أغلفة أنيقة (الاسم تحت الغلاف والتقييم على الغلاف).
- شاشة القناة الكاملة: شريط سفلي بشعار القناة ورقمها واسمها وتصنيفها، مع الساعة والشعار في الأعلى.
- الإعدادات: اختبار السرعة عبر Fast.com.
- المفضلة بالريموت: اضغط مطولاً على OK فوق الغلاف (على اللمس: النجمة على الغلاف).

## المراحل القادمة
3. البحث والتنزيلات.
4. الإعدادات والرقابة الأبوية وصقل التنقل بالريموت.

## البناء
1. افتح المجلد في Android Studio (Koala 2024.1.1 أو أحدث) واتركه يزامن Gradle.
2. شغّل على هاتف/محاكي أو جهاز Android TV.

أو عبر GitHub: ارفع المشروع، وسيبني `.github/workflows/android.yml` ملف
`app-debug.apk` تلقائياً، ويمكنك تنزيله من تبويب Actions ثم Artifacts.

> الأسماء الحالية مؤقتة: اسم التطبيق `strings.xml`، والحزمة `com.myiptv.app`، والشعار النصي في `activity_main.xml`.
> استخدم تطبيقك مع اشتراكات تملك حق استخدامها فقط.
